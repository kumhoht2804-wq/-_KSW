# 연구소 역량·교육 관리

제작자 **KSW** · © KSW. All rights reserved.

연구소 인원의 **역량평가**(파트별 Knowledge·Skill 등급 → 종합 Level)와 **교육 수료 현황**(필수·선택 교육, 부서별 이수율)을 함께 관리하는 사이트입니다.

- `index.html`: 사이트 화면 (GitHub Pages로 배포)
- `Code.gs`: 서버 코드 (구글 시트의 Apps Script에 붙여넣기)

직원 이름, 평가 등급, 계정 정보는 이 저장소에 없습니다. 모두 구글 시트에 저장되고, 로그인한 사람에게만 서버가 보여 줍니다.

## 처음 설정

1. 새 구글 시트 만들기 → **확장 프로그램 → Apps Script** → `Code.gs` 내용을 통째로 붙여넣고 저장
2. **배포 → 새 배포 → 유형 선택(톱니) → 웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - 권한 승인 창이 뜨면 허용 (고급 → 안전하지 않은 페이지로 이동)
3. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 `index.html`의 `DEFAULT_API`에 넣기
4. 사이트 접속 → **최초 관리자 만들기** → 로그인 후 **원본 엑셀 불러오기**로 역량평가·교육 현황 엑셀 두 파일을 함께 선택
5. **계정 관리**에서 엑셀 잠금 비밀번호 설정
6. 다른 사람은 로그인 화면의 **회원가입**으로 신청 → 관리자가 **계정 관리 → 가입 승인 대기**에서 역할을 정해 승인

## 역할

| 역할 | 할 수 있는 일 |
|---|---|
| 관리자 | 모든 화면 수정, 계정 관리, 엑셀 잠금 비밀번호 설정, 백업·복원 |
| 편집 | 역량평가 등급 입력, 교육 이수 등록·취소 |
| 보기 | 조회, 잠긴 엑셀 내보내기 |

## Code.gs를 고쳤을 때

**배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**를 해야 반영됩니다. (새 배포를 만들면 URL이 바뀌니 주의)
